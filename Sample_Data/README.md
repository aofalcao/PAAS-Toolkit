## Sample structure data for creating a small PAAS set

This folder comprises 20 AlphaFold structures in PDB format that can be read and used for PAAS test. The full PAAS data set constructed with a radius of 4.0 Angstroms over 540,000 SwissProt entries can be found [Here](https://zenodo.org/records/20082135) 

**The data comes from the Alpha fold structures deposited [here](https://alphafold.ebi.ac.uk/)**
